# Udviklingsplan

Planen er prioriteret efter afhængigheder og har endnu ingen lovede datoer.

## 0. Projektgrundlag — oprettet

- Vision, brugerrejse, privatlivsprincipper og afgrænsning.
- Offentligt repository og open source-licens.

## 1. Lokal teknisk prototype

- Afprøv lokal lagring, bilag, offlinebrug og komplet backup/gendannelse.
- Verificér understøttede browsere og håndtering af afbrudt gemning.
- Vælg teknologistak og dokumentér beslutningen.

Færdig når et testarkiv med bilag kan gemmes, genåbnes og gendannes uden netværk eller tab af data.

## 2. Første brugbare version

- Kort onboarding for bolig og brugerdefinerede områder.
- Et lille gennemgået sæt opgaveskabeloner.
- Dashboard, opgaver, gentagelser og historik.
- Manuel import af PDF, billeder og mailfiler.
- Lokal kalender og ICS-eksport.
- Dansk brugerflade, tastaturbetjening og backupvejledning.

Færdig når en bruger kan gennemføre hele forløbet fra opsætning til afsluttet opgave og gendannet backup.

## 3. Konto og kontrollerede integrationer

- Onlinekonto adskilt fra lokalt arkiv; lokal brug fortsat mulig.
- Én kalenderintegration med tydeligt datavalg og konflikthåndtering.
- Afprøv påmindelser med dokumenterede begrænsninger.
- Trusselsmodel og test før håndtering af rigtige kontooplysninger.

## 4. Flere livsområder og fællesskabsbidrag

- Familie, transport, aftaler, økonomiske påmindelser og selvstændig virksomhed.
- Versionsstyrede indholdspakker med kilder, kontroltidspunkt og lokal variation.
- Gennemgangsproces for fagligt indhold og bevaring af egne rettelser.

## 5. Valgfri deling og assistance

- Husstandsdeling, rettigheder og eventuel krypteret synkronisering.
- Lokal OCR og dokumentbaserede forslag med brugerens godkendelse.
- Flere lande og sprog, hvis fællesskabet kan vedligeholde indholdet.

## Uden for første version

Fuld bogføring, skatteberegning, automatisk indberetning, automatisk adgang til Digital Post, fuld mailimport, bankintegration og løfte om at dække alle danske pligter.
